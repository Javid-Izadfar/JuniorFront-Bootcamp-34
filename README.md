# JuniorFront Bootcamp 34

Materials, examples, exercises, and student work for **CodingFront — Junior Frontend Developer Bootcamp 34**.

This repository contains the code and resources used throughout the bootcamp, organized by session and exercise.

## Repository Structure

```text
.
├── s01/        # Session 01 examples and practice
├── e01/        # Exercise 01 — student submissions
├── configs/    # Development environment configuration
└── ...
```

### Sessions

Session folders contain examples and code written during class.

* `s01/` — Session 01
* `s02/` — Session 02
* `s03/` — Session 03

New session folders will be added as the bootcamp progresses.

## For Students

Keep your work inside the folder assigned to the relevant exercise.

For example:

```text
e01/
└── your-name/
    └── index.html
```

Try to keep your submissions simple and organized. The goal is to practice the concepts covered in class.

### VS Code Configuration

The [`configs/README.md`](./configs/README.md) file contains the recommended VS Code setup for the bootcamp.

Read it and configure your VS Code before continuing with the exercises. It includes the recommended extensions, formatting setup, fonts, and other useful editor settings.
